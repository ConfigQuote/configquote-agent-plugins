# Custom GPT Action Setup

Import the live tenant OpenAPI schema instead of copying a static schema:

```text
https://<tenant-domain>/api/agent/v1/openapi.json
```

Recommended OAuth scopes:

```text
configurations:read configurations:write quotes:read quotes:write quotes:send team:read
```

Redirect URLs are generated by ChatGPT for each GPT. Add the ChatGPT redirect URL to the tenant OAuth client when required by the host.
